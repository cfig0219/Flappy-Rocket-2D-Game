# Flappy Rocket: AI-Assisted Game Development 🚀

## 📖 Overview
This project is a recreation of the classic "Flappy Bird" mechanic, reimagined as **Flappy Rocket**. The primary objective was to explore the efficiency of **Generative AI** in assisting with cross-platform development, resulting in functional versions in both **Python** and **C++**. 

[cite_start]This repository serves as a case study in leveraging LLMs for rapid prototyping, logic translation, and UI optimization.

## 🛠️ Tech Stack & Tools
* [cite_start]**Languages:** Python (Pygame logic) and C++[cite: 12].
* [cite_start]**AI Integration:** Utilized Generative AI workflows to assist in UI revision and real-time interface modification.
* **Development Focus:** Bridging the gap between managed (Python) and unmanaged (C++) environments.

## 📁 Repository Structure
* **`FlappyRocketPython.py`**: The Python implementation utilizing game loops and sprite handling.
* **`FlappyRocket.cpp`**: The C++ implementation, focusing on performance and manual resource management.
* **`HW6Figueroa.pdf`**: Technical documentation and personal analysis of the AI-assisted development process.
* **`HW 6_ I Used AI to Make Flappy Bird.pdf`**: Original project specifications and creative brief.

## 🤖 AI Implementation Highlights
[cite_start]As part of my specialization in **Agentic AI and Prompt Engineering**, this project explored several key AI-driven development patterns:
1. **Code Translation:** Using AI to port physics and collision logic from Python to C++.
2. **Optimization:** Refactoring game loops for better frame-rate stability using AI-suggested patterns.
3. [cite_start]**Logic Refinement:** Leveraging Chain-of-Thought prompting to debug complex coordinate-based rocket sprites.

## 💻 How to Run

### Python Version
Ensure you have `pygame` installed, then run:

python FlappyRocketPython.py

### C++ Version
Ensure you have a C++ compiler (like `g++`) installed, then run:

# 1. Compile the source code into an executable named 'FlappyRocket'
g++ FlappyRocket.cpp -o FlappyRocket

# 2. Run the generated executable
./FlappyRocket
